# Мебель Азали

Премиальный концепт сайта-каталога для мастерской мягкой мебели
[Мебель Азали](https://vk.ru/mebelazali) (Стерлитамак).

## Локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

GitHub Pages деплоится из `main` через Actions (`.github/workflows/deploy.yml`).
